Sivuston ainoa ajettava käyttöliittymä: HTML-sivut, CSS ja selain-JS. Ei erillistä sovelluspalvelinta — sisältö ja logiikka toimitetaan staattisina tiedostoina.

## Responsibilities
- Renderöi pages/-sivut ja hydratoi dynaamiset osat ES-moduuleilla
- Hallitsee navigaation, teeman, projektien/harrastusten/taitojen näkymät
- Lukee sisältödatan JS-moduuleista ja mediat assets/-kansiosta

## Tech Stack
- HTML pages in `pages/`
- CSS in `css/`
- JavaScript ES modules in `js/`
