Sisällön “tietovarasto” ilman tietokantaa: versionhallinnassa olevat JS-datamoduulit, joista näkymät lukevat profiilin, projektit, harrastukset ja taidot.

## Responsibilities
- Pitää yllä `SITE`-profiilitiedot (`site-data.js`)
- Tarjoaa projektit, harrastukset ja taitokategoriat (`projects-data.js`, `hobbies-data.js`, `skills-data.js`)
- Toimii yksittäisenä lähteenä, jota sivut ja skriptit käyttävät

## Tech Stack
- JavaScript ES modules under `js/`
