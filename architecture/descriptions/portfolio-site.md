Staattinen portfolio-sivusto, joka esittelee tekijän osaamisen, projektit ja yhteystiedot ilman erillistä backendia tai tietokantaa.

## Responsibilities
- Tarjoaa monisivuisen esittelyn (home, about, experience, projects, skills, education, hobbies, contact)
- Ajaa kaiken vuorovaikutuksen selaimessa (navigaatio, teema, suodatukset, galleriat)
- Linkittää ulospäin GitHubiin, LinkedIniin ja Instagramiin

## Tech Stack
- HTML5, CSS3, vanilla JavaScript (ES modules)
- Staattinen tiedostopalvelu (paikallisesti `serve`, tuotannossa staattinen hostaus)
